❓ Frequently Asked Questions
Aapke common questions ka jawab
Q1: Kya mera existing data migrate hoga?
Haan, bilkul. Aapke existing customers, subscriptions, invoices — sab kuch ResellerOS me migrate ho jayega. Migration script Phase 1 me hi run karenge. Aapko ek baar verify karna padega, fir purana system band kar sakte ho.
Q2: Project ke baad maintenance ka kya?
Support period me (3-12 months depending on plan) sab bug fixes free hain. Uske baad annual maintenance contract le sakte ho ₹50K/year se shuru. Ya khud manage kar lo — source code aapka hai.
Q3: Source code mera hoga?
Haan, **full source code ownership** aapko milta hai. Project deliver hone ke baad GitHub access transfer ho jayega. Aap chahein toh future me kisi aur developer se bhi kaam karwa sakte ho.
Q4: Tech stack kya hai? Future me extend ho payega?
Vite + Vanilla JS + Firebase Firestore + Cloud Functions. Modern, modular, scalable. New features add karna easy hai. Industry-standard tools — koi propriety lock-in nahi.
Q5: Team ko training kaise milegi?
2 dedicated training sessions included hain — ek admin team ke liye (settings, automation), doosri sales/finance team ke liye (daily usage). Plus video tutorials aur written SOPs (Standard Operating Procedures) bhi milenge.
Q6: Agar beech me scope change karna ho?
Phase boundaries pe scope change kar sakte ho. Phase 1 sign-off ke baad Phase 2 ka scope finalize hota hai. Mid-phase changes possible hain lekin uska additional cost lagega — separate change request raise karna padta hai.
Q7: Multi-vendor (Google + Microsoft + Zoho) ek saath manage kar sakte hain?
Haan — Enterprise plan me. Items catalog me har vendor ke SKUs separately, customer portal me filter, alag-alag landing pages — sab ready hai. Reseller API integration teeno vendors ke liye.
Q8: GST compliance properly handle hota hai?
Bilkul. CGST + SGST (intra-state), IGST (inter-state) — automatic state-based detection. HSN code (998313) auto-populate. GSTR-1 friendly export. PDF invoices fully GST-compliant. Future me e-invoice IRN support bhi add ho sakta hai.
Q9: Mobile app bhi milega?
PWA (Progressive Web App) milega — phone me browser se khol ke "Add to Home Screen" karo, app jaisa kaam karega. Offline mode, push notifications, camera (photo capture), GPS check-in — sab kuch. Native iOS/Android app nahi hai abhi, lekin PWA usually enough hai 95% use cases ke liye.
Q10: Data security kaisa hai?
Firebase Auth + Firestore Security Rules + Cloud Functions. Multi-tenant architecture — aapke data dusre kisi tenant ko nahi dikhega. RBAC (Role-Based Access Control) — sales rep apne hi leads dekhe, support tickets owner-only, etc. Data India region (asia-south1, Mumbai) me hai. Sentry error monitoring. Daily Firestore backups.
Q11: Payment terms kya hain?
25% kick-off pe, fir 4 milestones pe 15-20% har baar. Total payment 8 weeks me distribute hota hai. Razorpay/Bank/UPI — koi bhi mode chalega. Invoice GST ke saath milega har milestone pe.
Q12: Agar project complete time pe nahi hua to?
8-week timeline aggressive lekin realistic hai. Milestone-based delivery hota hai — har 2 weeks pe demo + sign-off. Agar koi delay hota hai (mere taraf se), aapko advance notice milega aur plan adjust karenge. Aap bhi timely feedback dein — har milestone pe.
Q13: Existing gw-pro system ka kya hoga?
gw-pro hi base hai ResellerOS ka — usko enhance kar rahe hain. Aapka existing data, settings, integrations — sab kuch reuse hoga. Brand rename ho sakta hai (ResellerOS), URL change kar sakte ho, but core system continuous hai.
