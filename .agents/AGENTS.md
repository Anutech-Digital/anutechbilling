# Workspace Rules & Directives

## GitHub Pushing Rule
- Whenever code changes or feature updates are completed, ALWAYS stage, commit, and push all changes directly to the `main` branch of the `anutech` remote repository (`https://github.com/pardeepwebmaster/anutechbilling.git`):
  ```bash
  git add .
  git commit -m "<descriptive message>"
  git push anutech HEAD:main
  ```
